Reconstruct research. Do not detach it from its evidence.

A traceable specification for ingesting scholarly sources, historical editions, field notes, interviews, and experiment records while preserving passages, evidence, claims, reasoning, uncertainty, and review state.

Read the skill Open GitHub
Project status. This is an English Codex skill and specification, not a compiled parser.

What the structure protects

The goal is not a smoother summary. The goal is a research record that can return to the original, survive repeated processing, support cross-source reuse, and remain auditable by a human researcher.

Provenance

Original text remains retrievable

Passages keep file, page, paragraph, character range, note, and image-region anchors.

Argument

Reasoning remains inspectable

Claims, arguments, reasoning steps, warrants, and evidence use are separate objects.

Review

Uncertainty remains visible

Certainty, reliability, classification confidence, and verification state are not collapsed.

P0–P5 processing order

Stages describe the order of work, not the final folder structure. Each stage may write to several output groups.

P0Intake and safety

Register files, integrity, OCR state, missing regions, and untrusted-source boundaries.

P1Original and structure

Preserve the source; create Passages, sections, citations, and bibliography.

P2Explicit objects

Extract entities, concepts, materials, editions, time, evidence, observations, and experiments.

P3Argument reconstruction

Build Issues, Claims, Arguments, ReasoningSteps, Warrants, limitations, and open questions.

P4Relations and reuse

Create reviewable relations, internal links, evidence uses, and deduplication candidates.

P5Coverage and validation

Merge chunked runs; report ambiguity, coverage, review queues, and validation results.

Structured package + human map

Machine-readable groups preserve the research record. A separate human-readable map provides the overview without replacing the underlying evidence. 

00_manifest.*          intake, versions, and coverage
02_original_archive/   original source and page index
03_bibliography/       citations and occurrences
04_structure/          sections and Passages
05_argument/           claims, arguments, reasoning, evidence use
06_semantics/          entities, concepts, materials, editions, time
07_practice/           fieldwork, experiments, observations, memos
08_links/              proposition, link, and deduplication candidates
09_quality/            run logs, ambiguity, review queues, validation
